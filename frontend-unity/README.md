# frontend-unity

The Unity VR project lives here (project name: SASLTutorVR).

Unity version: 6.5 (6000.5.4f1) — everyone must use this exact version.
Opening the project in any other version rewrites ProjectSettings/ and
Packages/ and breaks it for everyone. Never commit changes to those folders
unless the whole team has agreed to change versions.

The project already exists in the repo, so don't create a new one. In Unity
Hub use Add -> "Add project from disk" and select frontend-unity/SASLTutorVR/.
Work on a feature branch off `develop` (see the root README).
